# Learning Assistant

Learning Assistant 将书籍、章节、学术论文、研究报告或课程材料转化为结构化学习笔记，使其可以复习、检索并继续用于研究。它不替代读者形成最终观点。

## 它解决什么问题

学习之后常常只留下零散划线，或一份过度压缩的摘要。这个 Skill 保留两者之间真正可用的一层：

原始材料 → 结构化提取 → 研究连接 → 可复用学习笔记

它提取材料的问题、观点、证据、概念与分歧；谨慎连接到研究方向；再留下后续问题与可沉淀的知识候选。

## 适合谁使用

- 阅读书籍、论文和报告的学生与研究者。
- 建设长期知识库的政策、治理、科技与国际关系研究者。
- 需要在工作中准确保留课程、报告或逐字稿论证内容的专业人士。

这是一个通用工具。研究问题是可选输入，适用于任何领域。

## 支持什么输入

v1.0 支持用户提供的书籍或章节、学术论文、研究/政策报告、课程讲义或逐字稿。文件格式支持 PDF、Markdown 和纯文本。

可选的第二项输入是读者当前要解决的问题；若未提供，则从材料自身的核心问题开始。

## 会输出什么

每份笔记都使用稳定的 Markdown 结构，包含七部分：

1. 核心问题
2. 最多五条核心观点
3. 原文所述的证据与方法
4. 最多五个核心概念
5. 与研究方向的有限关联
6. 最多三个后续研究问题
7. 概念笔记、案例笔记和待验证判断候选

笔记使用固定 YAML frontmatter 与 [模板](templates/learning-note.md)。每份材料会选择一个主领域，必要时选择一个次领域：国际关系与国际政治经济、欧洲政治、科技政治与技术主权、AI 治理与 AI 安全、AI 产业与基础设施。

## 如何使用

将 `learning-assistant` 目录安装或复制到 Codex 的 Skills 目录，然后这样调用：

```text
使用 $learning-assistant 阅读这篇论文。
我当前的问题是：技术依赖如何转化为国家权力？
请生成结构化学习笔记。
```

或：

```text
使用 $learning-assistant 将附件中的报告转化为结构化学习笔记。
```

笔记默认使用中文。为保证精确性，原文术语、引文、机构和作品标题应在必要时保留原始语言。

## 研究护栏

- **以原文为准。** 用户提供的材料是权威，Skill 不会静默补充背景知识。
- **边界清晰。** 作者观点、材料证据、Skill 推论和外部补充不会混写。
- **不伪造确定性。** 不清楚或未出现的内容标记为 `材料中未充分说明。`
- **保留分歧。** 不将存在争议的观点强行压缩成单一结论。
- **不借用用户判断。** `我的判断候选` 必须标记为 `待用户 / 研究负责人验证`。

## v1.0 不做什么

它不会自动搜索补充来源、评价论文质量、生产公开内容、建立知识图谱、同步数据库或生成最终 Evergreen Note。这些是有意保留的边界。
