# 学习助手

从用户提供的 PDF、Markdown 或文本材料中生成结构化学习笔记。目标是提取、理解、连接并沉淀知识，而不替代用户的智识判断。

## 输入

必须提供原始材料。可选的当前研究问题可以影响侧重点，但不得改变材料原意。

v1.0 支持书籍或章节、学术论文、研究报告、课程讲义或逐字稿，格式为 `.pdf`、`.md` 或 `.txt`。本地文件需要提取文字或判断材料类型时，先运行 `scripts/prepare_material.py`。若提取失败，应报告具体限制并请求可读文本；不得从文件名或外部知识推断内容。

## 工作流程

1. 起草前先阅读材料，识别材料类型、核心问题、主要观点、材料中陈述的证据或方法、概念、分歧与限制。
2. 从 [输出约定](references/output-contract.md) 的受控词表中选择一个主领域；仅在确有必要时选择一个次领域。
3. 始终区分作者观点、材料支持的证据和本技能明确标注的推论。
4. 将材料与用户提供的研究问题或所选领域关联。这一关联用于解释可能的研究价值，而不是形成结论。
5. 严格使用 [学习笔记模板](templates/learning-note.md) 中的 YAML frontmatter 和七个部分。不得添加执行摘要、评分、网页链接、内容选题或额外章节。
6. 对保存后的笔记运行 `scripts/validate_note.py`，在交付前修正结构性错误。

## 来源与判断规则

- 将用户提供的材料视为权威，不得用模型知识静默填补空白。
- 如需用外部事实澄清语境，应在相应部分标记 **外部补充：**，并说明其不来自材料。除非用户明确要求，v1.0 不使用外部研究。
- 若材料未充分说明证据、方法、元数据或某一主张，写作 **材料中未充分说明。**
- 不得压缩或抹平分歧。适用时，写作 `A认为…；B认为…；作者倾向于…`，并明确每种立场的归属。
- 核心观点必须是完整命题而非主题标签。核心观点、概念和后续问题分别最多五个、五个和三个。
- `我的判断候选` 只能包含与原文相关的暂定可能性，且必须保留 **待用户 / 研究负责人验证**。不得将其表述为用户观点或最终结论。

## 边界

本技能不联网搜索、不评价论文质量、不生成常青笔记、不建立知识图谱、不同步数据库，也不将研究转化为公开内容。它不对用户提供材料之外的真实性作出裁定。

## 测试

修改本技能前，请运行 `python3 -m unittest discover -s tests`。三类依赖原始材料的验收案例位于 [验收案例](tests/cases/README.md)，仅可使用合法获得的原始材料运行。
