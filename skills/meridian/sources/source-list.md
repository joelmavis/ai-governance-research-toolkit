## 使用规则

1. 来源优先顺序：官方一手来源 → 国际组织/学术机构/智库 → 权威媒体 → 企业官方 → 研究者账号 → 社交媒体线索。
2. 同一政策或事件被多家媒体转载时，按一个事件处理，并记录最关键的一手来源与必要补充来源。
3. 媒体、社交平台和播客只作为线索时，应寻找原始文件；无法取得时，要明确标注来源层级和限制。
4. 企业公告须区分承诺、已部署能力与独立验证结果。
5. 研究者和社交媒体线索必须标为线索，不能单独证明重要事实。
