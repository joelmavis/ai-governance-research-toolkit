# 界标（Meridian）

界标是 AI 治理研究的情报雷达。它每天从大量动态中筛出最多三个真正值得关注的信号，优先解释变化对权力、主权、治理、技术依赖和企业意味着什么。

## 如何使用

```text
使用 $meridian 扫描过去 24 小时的欧洲科技政治与 AI 治理动态。
请生成每日情报雷达；最多三条，并优先提供一手来源。
```

也可以限定研究线：

```text
使用 $meridian 查看本周中美欧芯片、出口管制和 AI 基础设施相关变化。
请输出周度情报雷达，并主动保留反向信号。
```
