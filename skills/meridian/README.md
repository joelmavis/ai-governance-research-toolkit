# Meridian

Meridian 是面向 AI 治理研究的情报雷达。它不是新闻聚合器；它的工作是在有限时间内，从大量动态中筛出最多三个真正值得继续研究的信号，并说明这些变化对权力、主权、治理、技术依赖和企业意味着什么。

## 它解决什么问题

研究者每天会遇到大量政策公告、公司发布、媒体报道和社交平台讨论。真正困难的不是“找到更多信息”，而是判断：哪些事件发生了实质变化、是否有可靠原始来源、是否值得占用下一小时的研究时间。

Meridian 将这个判断过程固定为一套可复用的流程：按事件去重、识别变化、回到一手来源、保留反向信号，再把结果收束成可执行的下一步。

## 适合谁使用

- 跟踪欧洲科技政治、AI 治理或技术主权的研究者和学生
- 关注中美欧科技关系、出口管制、算力、云与供应链的分析者
- 需要观察企业 AI 部署、合规、安全与采购要求的政策或产品团队
- 希望把日常信息收集转化为研究问题或内容选题的独立研究者

它也适合已有明确主题但不想被新闻流淹没的人。它不适合需要实时预警、全网舆情监测或自动发布内容的场景。

## 监控范围

Meridian 只在四条研究线上工作：

1. 欧洲科技政治：数字政策、技术主权、战略自主、产业政策与科技安全。
2. AI 治理与 AI 主权：监管、安全、模型治理、标准，以及算力、数据和云主权。
3. 中美欧科技关系：芯片、出口管制、AI 竞争、供应链、技术联盟与规则竞争。
4. 企业 AI 治理：部署方式、数据保护、私有化部署、安全、合规与采购要求。

## 如何使用

### 每日扫描

```text
使用 $meridian 扫描过去 24 小时的欧洲科技政治与 AI 治理动态。
请生成每日情报雷达：最多三条，优先提供一手来源，并说明建议动作。
```

### 围绕具体问题扫描

```text
使用 $meridian 查看本周中美欧芯片、出口管制和 AI 基础设施相关变化。
请输出周度情报雷达，并主动保留挑战既有判断的反向信号。
```

### 追踪企业治理变化

```text
使用 $meridian 关注过去一周欧洲企业 AI 采购、数据治理和私有化部署的新要求。
只保留有公开文件或官方说明支持的变化。
```

## 它如何工作

1. 从分层来源中寻找与指定时间范围相关的候选事件。
2. 按“事件”而非“报道篇数”去重；同一政策被多家媒体转载仍只算一个信号。
3. 判断它是否带来政策、标准、战略、依赖关系、基础设施、企业实践或研究理解上的变化。
4. 将媒体、播客和社交平台作为发现入口，并尽量补充原始文件。
5. 优先输出 P1，以及最有价值的 P2；P3 只在明确要求时列出。
6. 为每个核心信号给出一个明确动作：忽略、保存、快速研究、专题研究或内容选题。

## 输出与价值

每日输出最多三条信号，每条固定说明“发生了什么”“为什么重要”“所属研究方向”“来源”和“建议动作”。周报则把五个重要信号进一步整理为共同变化、可继续研究的问题和内容候选。

这种结构带来三点便利：减少重复阅读同一事件的转述；将“热度”与“研究价值”分开；让每条信息都有可追溯来源和下一步，而不是停留在收藏夹里。

## 来源与判断边界

来源优先级为：官方一手来源、国际组织/学术机构/智库、权威媒体、企业官方、研究者账号、社交媒体线索。社交平台与播客可以帮助发现议题，但不能单独证明重要事实；重要结论应回到可访问的原始文件。

Meridian 会主动保留政策退坡、成员国分歧、项目失败、企业抵制或技术依赖加深等反向信号。它可以提出“这可能意味着”，但不替任何用户形成最终判断，也不宣布长期趋势已经成立。
