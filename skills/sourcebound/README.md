# 源锚（Sourcebound）

源锚是一项面向严肃阅读与长期研究的 Codex 技能。它将书籍、章节、学术论文、研究报告和课程材料，转化为结构化、可检索、可继续用于研究的学习笔记。

它不替读者学习，也不替读者形成结论。它做的是：**提取 → 理解 → 连接 → 沉淀**。

“源锚”意味着以原始材料为锚：材料说了什么、证据支持到哪里、哪些部分只是暂定推论，必须始终分开。

## 为什么使用源锚

阅读后的难点往往不是信息不足，而是知识难以再次使用：划线分散在不同载体里，摘要丢失论证结构，概念也无法接入已有研究。

```text
原始材料 → 结构化提取 → 研究连接 → 可复用学习笔记
```

它提供四项实际便利：

- **减少重复整理。** 每份材料使用相同结构，便于复习、比较与检索。
- **保留证据边界。** 作者观点、材料证据、技能推论与外部补充不会混写。
- **连接研究，而非堆积摘要。** 笔记说明材料能帮助理解什么，并保留后续研究问题。
- **保留人的判断权。** 它只提出待验证的判断候选，不把模型表述伪装成读者结论。

## 适合谁使用

- 阅读书籍、论文和报告的学生与研究者。
- 建设长期知识库的政策、治理、科技与国际关系研究者。
- 需要准确保留课程、报告或逐字稿论证内容的专业人士。
- 希望把阅读转化为研究资产，而不是收集更多零散笔记的人。

这是一个通用工具。研究问题是可选输入，适用于任何领域；当前的领域标签尤其适合 AI 治理、技术主权、欧洲政治、国际关系与 AI 基础设施研究。

## 支持什么输入

v1.0 支持用户提供的书籍或章节、学术论文、研究/政策报告、课程讲义或逐字稿，格式为 PDF、Markdown 和纯文本。除原始材料外，可以额外提供一个当前研究问题；若没有，源锚会从材料自身的核心问题开始。

## 会输出什么

每份笔记都使用固定 Markdown 结构，严格包含七部分：

1. 核心问题
2. 最多五条核心观点
3. 原文所述的证据与方法
4. 最多五个核心概念
5. 与研究方向的有限关联
6. 最多三个后续研究问题
7. 概念笔记、案例笔记和待验证判断候选

笔记使用固定 YAML frontmatter 与 [学习笔记模板](templates/learning-note.md)。每份材料会选择一个主领域，必要时选择一个次领域：国际关系与国际政治经济、欧洲政治、科技政治与技术主权、AI 治理与 AI 安全、AI 产业与基础设施。

## 如何使用

将 `sourcebound` 目录安装或复制到 Codex 的技能目录，然后在对话中显式调用 `$sourcebound`。最好同时提供材料和当前研究问题。

### 用例一：阅读学术论文

```text
使用 $sourcebound 阅读附件中的 Weaponized Interdependence 论文。
我当前的问题是：技术依赖如何转化为国家权力？
请生成结构化学习笔记。
```

适合提炼理论命题、经验案例与核心概念，并将其谨慎接入国际政治经济或技术主权研究。

### 用例二：消化一本书的单章

```text
使用 $sourcebound 阅读附件中《Governing AI》的第 3 章。
请重点回答：该章节界定了什么治理问题，又讨论了哪些治理工具？
```

适合避免把全书观点误归给单一章节，同时留下可回到原文核对的章节级证据。

### 用例三：处理政策或研究报告

```text
使用 $sourcebound 将附件中的 AI 治理报告转化为学习笔记。
请区分报告的事实发现、政策建议和材料中未充分说明的内容。
```

适合快速建立政策比较的共同结构，而不把建议误写成已被证实的事实。

### 用例四：整理课程讲义或逐字稿

```text
使用 $sourcebound 阅读附件中的课程逐字稿。
不预设研究问题；请先识别讲者试图回答的核心问题，再生成学习笔记。
```

适合将课程内容转化为后续可以复习、交叉比较和继续研究的知识资产。

## 得到笔记后怎么用

源锚输出的笔记不是最终文章或最终观点。建议：先回到原文核对关键命题与证据；再将核心概念和案例候选纳入知识库；只在核对后讨论或保留“我的判断候选”。

## 研究护栏

- **以原文为准。** 用户提供的材料是权威，技能不会静默补充模型知识。
- **边界清晰。** 作者观点、材料证据、技能推论和外部补充不会混写。
- **不伪造确定性。** 不清楚或未出现的内容标记为 `材料中未充分说明。`
- **保留分歧。** 不将存在争议的观点强行压缩成单一结论。
- **不借用用户判断。** `我的判断候选` 必须标记为 `待用户 / 研究负责人验证`。

## v1.0 不做什么

它不会自动搜索补充来源、评价论文质量、生成公开内容、建立复杂知识图谱、同步数据库或直接生成最终 Evergreen Note。这些是有意保留的边界。
