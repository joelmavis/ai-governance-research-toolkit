# 源锚（Sourcebound）

源锚将书籍、章节、学术论文、研究报告或课程材料转化为结构化学习笔记，使其可以复习、检索并继续用于研究。它不替代读者形成最终观点。

## 名称含义

“源锚”意味着以原始材料为锚。所有观点、证据与推论都必须保持清晰边界。

## 适合谁使用

适用于希望将阅读材料转化为长期研究资产的学生、研究者和专业人士。

## 如何使用

将 `sourcebound` 目录安装到 Codex 的技能目录，然后调用：

```text
使用 $sourcebound 阅读这篇论文。
我当前的问题是：技术依赖如何转化为国家权力？
请生成结构化学习笔记。
```

## 研究护栏

- 以原文为准，不静默补充模型知识。
- 区分作者观点、材料证据与技能推论。
- 不替用户制造最终判断；判断候选必须标记为待验证。

## 当前状态

v1.0：支持 PDF、Markdown 和纯文本材料；输出稳定的七部分学习笔记。
