# Sourcebound


Sourcebound 是一项面向严肃阅读与长期研究的 Codex 技能。它将书籍、章节、学术论文、研究报告和课程材料，转化为结构化、可检索、可继续用于研究的学习笔记。


它不替读者学习，也不替读者形成结论。它做的是：**提取 → 理解 → 连接 → 沉淀**。


Sourcebound 的工作原则是以原始材料为锚：材料说了什么、证据支持到哪里、哪些部分只是暂定推论，必须始终分开。


## 为什么使用 Sourcebound


阅读后的难点往往不是信息不足，而是知识难以再次使用：划线分散在不同载体里，摘要丢失论证结构，概念也无法接入已有研究。


```text
原始材料 → 结构化提取 → 研究连接 → 可复用学习笔记
```


它提供四项实际便利：


- **减少重复整理。** 每份材料使用相同结构，便于复习、比较与检索。
- **保留证据边界。** 作者观点、材料证据、技能推论与外部补充不会混写。
- **连接研究，而非堆积摘要。** 笔记说明材料能帮助理解什么，并保留后续研究问题。
- **保留人的判断权。** 它只提出待验证的判断候选，不把模型表述伪装成读者结论。


## 适合谁使用


- 阅读书籍、论文和报告的学生与研究者。
- 建设长期知识库的政策、治理、科技与国际关系研究者。
- 需要准确保留课程、报告或逐字稿论证内容的专业人士。
- 希望把阅读转化为研究资产，而不是收集更多零散笔记的人。


这是一个通用工具。研究问题是可选输入，适用于任何领域；当前的领域标签尤其适合 AI 治理、技术主权、欧洲政治、国际关系与 AI 基础设施研究。


## 支持什么输入


v1.0 支持用户提供的书籍或章节、学术论文、研究/政策报告、课程讲义或逐字稿，格式为 PDF、Markdown 和纯文本。除原始材料外，可以额外提供一个当前研究问题；若没有，Sourcebound 会从材料自身的核心问题开始。


## 会输出什么


每份笔记都使用固定 Markdown 结构，严格包含七部分：


1. 核心问题
2. 最多五条核心观点
3. 原文所述的证据与方法
4. 最多五个核心概念
5. 与研究方向的有限关联
6. 最多三个后续研究问题
7. 概念笔记、案例笔记和待验证判断候选


笔记使用固定 YAML frontmatter 与 [学习笔记模板](templates/learning-note.md)。每份材料会选择一个主领域，必要时选择一个次领域：国际关系与国际政治经济、欧洲政治、科技政治与技术主权、AI 治理与 AI 安全、AI 产业与基础设施。


## 如何使用


将 `sourcebound` 目录安装或复制到 Codex 的技能目录，然后在对话中显式调用 `$sourcebound`。最好同时提供材料和当前研究问题。
