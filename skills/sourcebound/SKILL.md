# 源锚（Sourcebound）

以原始材料为锚，生成结构化学习笔记，而不替代用户的智识判断。

## 输入

必须提供原始材料；可选研究问题只影响侧重点，不得改变原意。v1.0 支持书籍、论文、研究报告与课程材料的 PDF、Markdown 和纯文本格式。

## 工作流程

1. 先阅读材料，识别核心问题、观点、证据、概念、分歧与限制。
2. 区分作者观点、材料证据与明确标记的技能推论。
3. 选择一个主领域，必要时选择一个次领域。
4. 严格输出学习笔记模板的七个部分。

## 研究规则

- 不得用模型知识静默补充材料。
- 材料未充分说明时，明确写作“材料中未充分说明”。
- 不抹平分歧；不得将判断候选表述为用户观点或最终结论。

## 边界

本技能不联网搜索、不评价论文质量、不建立知识图谱、不生成公开内容，也不对材料之外的真实性作出裁定。
