# Signalcraft

Signalcraft 用于把已经审核的研究材料变成可继续编辑的公开表达。它不会重新研究或替你决定立场；它让一份研究底稿在公众号、视频号和 X 上各自找到适合的角度、结构与语言。

## 适合什么场景

- 已完成专题研究，准备写一篇面向普通读者的公众号文章
- 想把复杂研究问题讲成四至八分钟的视频号口播
- 希望持续公开研究过程，但不把长文机械拆成社交媒体碎片
- 已有清楚判断，想检查其表达是否仍然忠于原始证据

它不适合资料还未核实的热点、需要补做研究的问题，或要求自动发布的任务。

## 如何使用

```text
使用 $signalcraft 基于以下已审核研究底稿创作内容。
主题：欧洲 AI 主权
核心问题：欧洲没有技术霸权，能否拥有 AI 主权？
核心判断：AI 主权不必等同技术完全自给，更关键的是保持关键领域的行动能力和选择权。
平台：公众号 + 视频号 + X
```

Signalcraft 会先提出可延展的内容母题，再为每个平台分别设计表达。公众号负责把问题研究透；视频号负责把一个矛盾讲明白；X 则让一条观察或判断可以独立公开。

## 你会得到什么

- 公众号：3–5 个标题候选、核心判断、文章结构与初稿
- 视频号：标题、15 秒钩子、三个关键事实、解释、判断与结尾
- X：3–5 条可独立成立的候选帖

如果材料不足，文稿会留下 `[待补：……]`，而不是虚构数据、时间、政策内容或引语。正式发布前，仍应进入事实核查环节。
