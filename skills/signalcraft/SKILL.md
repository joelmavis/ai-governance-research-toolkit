# Signalcraft

将已经完成并审核的研究材料，转化为符合“咖喱辣椒Joe”定位的公众号、视频号与 X 初稿。工作范围是选角度、搭结构、转换表达、生成初稿；不重新研究事实，也不替用户创造新的结论。

## 输入与前提

至少接收一项已审核输入：研究底稿、学习笔记、确认的情报信号，或 Joe / Elias 已明确给出的核心判断。尽量同时确认主题、核心问题、核心判断、目标平台、目标读者、已有材料和是否结合热点。

材料未支持的数字、时间、引语、案例或政策内容不得自行补充。需要它们才能完成表达时，使用显式占位符，例如：`[待补：欧洲云市场对美国公司的依赖数据]`。占位符不是事实，也不应在发布前保留。

## 内容母题与工作流程

先从已审核材料建立内容母题，再选择每个平台最适合的表达角度。一个研究项目可以形成深度内容、热点内容、概念内容和短内容，但不能把同一篇文稿机械裁剪后复制到三个平台。

1. 读取材料，列出已确认事实、他人判断与 Joe / Elias 已确认的判断。
2. 提取材料真正回答的核心问题及其中的张力。
3. 用“事件 → 制度 → 权力 → 判断”设计角度：不仅说明发生了什么，还解释其改变的制度安排、权力关系或结构性选择。
4. 按平台分别设计标题、开头、结构与初稿。
5. 逐项检查事实、他人判断和 Joe 判断是否清楚区分；检查是否超出材料证据。
6. 随后交给 Joe / Maya 审核，并在发布前交由事实核查 Skill 复核。

## 平台规则

### 公众号

输出三至五个带具体问题和张力的标题候选、一句核心判断、文章结构和中文初稿。默认结构为：发生了什么 → 真正的问题 → 为什么会这样 → 政治/经济/技术结构 → Joe 的判断 → 值得关注的下一步。

文字应有研究感但不写成论文，普通读者能理解；保留个人判断但不重复结论，不使用空泛结尾或标题党。

### 视频号

重新寻找最值得讲的一个矛盾，而不是压缩公众号。输出标题、前十五秒钩子、三个关键事实、核心解释、一个有边界的 Joe 判断，以及留下问题的结尾。默认是四至八分钟真人出镜脚本，采用评论解释型表达，而非课堂讲授。

### X

默认以中文为主，针对同一研究给出三至五条可独立成立的候选帖：动态观察、研究问题、数据/论文、短判断或研究结论。每条都应有自己的完整语义，不把长文强拆成十条线程。

## 表达与事实纪律

- 事实：材料可直接支持的内容；他人判断：明确归因给作者、机构或专家；Joe 判断：仅来自已审核材料或 Joe / Elias 明确提供的立场。
- 允许增强可读性，不允许增强事实。标题可以有张力，但不能伪造冲突、夸大因果或制造未被支持的对立。
- 对复杂或争议议题保留不确定性；不得为了流畅而压平学术分歧或反例。
- 内容服务长期个人 IP：欧洲研究背景、AI 行业实践与 AI 治理研究；不为短期流量偏离研究主线。
- v1.0 不自动配图、发布、定时、追热点、生成封面、做 SEO、模仿具体创作者文风，或根据流量改变研究立场。

## 与研究链路的关系

Sourcebound 提供长期知识，Meridian 发现信号，Parallax 形成专题研究底稿，Signalcraft 转化为公开表达。事实核查是发布前的独立最终环节；Signalcraft 不得绕过它。
