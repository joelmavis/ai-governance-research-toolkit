# Parallax

Parallax 用于把一个明确问题推进为一份可以回看、核查和继续讨论的研究底稿。它不追求把所有资料压缩成一个结论，而是让事实、不同解释、反例、证据强度与未解决问题各自留在清晰的位置。

## 适合什么任务

- 比较不同国家或地区的 AI、技术主权与产业政策
- 研究一项监管、基础设施或供应链变化的实际意义
- 梳理企业 AI 治理、私有化部署、合规与安全之间的关系
- 在写文章、做演讲或形成个人判断前，先建立可审核的证据底稿

它不做每日新闻扫描、实时舆情监控、最终立场判断或内容成稿。若研究问题仍然模糊，应先把问题收窄，而不是让它泛化为关键词检索。

## 如何使用

```text
使用 $parallax 研究：欧洲在依赖美国 AI 技术的情况下，能否建立 AI 主权？
范围：欧盟，2024–2026；重点：算力、云、基础模型、政策能力。
```

也可以检验政策变化或挑战一个企业治理假设：

```text
使用 $parallax 研究：私有化部署是否一定能够提高企业 AI 治理水平？
重点检验支持这一命题的条件、成本与反例。
```

## 输出会包含什么

每份底稿固定包含研究问题、最多五个子问题、可确认事实、至少两种主要解释、反例、证据强度、当前可形成的判断、未解决问题和完整参考来源。最终判断始终标注为“待 Joe / Elias 审核”。

它让每条材料知道自己回答了哪个问题；把事实与解释分开；在结论形成前保留反证和不确定性。后续事实核查或内容创作可以追溯到同一份底稿，而不是重新从收藏夹开始。
