# 技能
































这里存放服务于稳定研究工作流的可复用智能体技能。
































每个技能都应说明目的、输入、输出、研究规则、人工审阅点、限制、示例与版本。技能可以减少机械劳动，但不能替代证据评估或解释性判断。
































## 已有技能
































- [Sourcebound](sourcebound/README.md) — 将用户提供的学习材料转化为忠于原文、可继续用于研究的结构化学习笔记。
- [Verity](verity/README.md) — 核查研究与内容中的关键事实、来源、时间状态与推理边界。
