# Skills

这里存放一组服务于研究、观察、写作与核查工作流的可复用智能体技能。它们的共同目标不是替代人的判断，而是让材料、证据、推理和表达更有结构、更可追溯，也更便于人工审核。

## 适用范围

这套技能并不只适用于 AI、技术或政策研究。只要任务涉及阅读材料、跟踪变化、研究一个问题、把研究转成公开表达，或在发布前核查事实，都可以使用。常见场景包括：

- 公共政策、国际关系、商业与产业、科技、社会议题等主题研究
- 学术阅读、课程学习、报告与案例分析
- 行业观察、企业战略、市场与竞争研究
- 面向公众的文章、视频、社交媒体与研究通讯
- 任何需要清楚区分事实、解释、推论和个人判断的知识工作

它们不替代领域专家、法律/医疗等专业意见，也不自动决定立场或发布内容。涉及高风险、时效性或争议性信息时，应由使用者审核，并在需要时回到一手来源。

## 已有 Skills

- [Sourcebound](sourcebound/README.md) — 将用户提供的学习材料转化为忠于原文、可继续用于研究的结构化学习笔记。
- [Meridian](meridian/README.md) — 从高质量来源中筛选每天最多三个值得继续研究的情报信号。
- [Parallax](parallax/README.md) — 将明确研究问题转化为可追溯、可审核的研究底稿。
- [Signalcraft](signalcraft/README.md) — 将已审核研究材料转化为适配公众号、视频号和 X 的公开表达初稿。
- [Verity](verity/README.md) — 核查研究与内容中的关键事实、来源、时间状态与推理边界。

## 推荐使用流程

不同任务不必强行走完整链路。以下是从材料到公开表达的一条常用路径：

```text
已有书籍、论文、报告、课程材料
                ↓
           Sourcebound
      形成可复用的学习笔记
                ↓
日常动态或值得追踪的变化 → Meridian
                ↓
           Parallax
      形成专题研究底稿
                ↓
          Signalcraft
   生成适配不同平台的内容初稿
                ↓
            Verity
   核查事实、引用、时间与推理边界
                ↓
        使用者最终审核与发布
```

也可以按任务直接调用：想沉淀一份材料时使用 Sourcebound；想从信息流里找变化时使用 Meridian；想研究一个明确问题时使用 Parallax；已有审核材料、准备公开表达时使用 Signalcraft；发布前或研究中需要核查时使用 Verity。

## 使用原则

1. **证据先于表达。** 重要事实尽量回到可访问的一手来源。
2. **问题先于关键词。** 材料和搜索应服务于具体问题，而不是无边界堆积信息。
3. **事实、解释与使用者判断分开。** 判断必须来自已有证据或使用者明确提供，不能由 Skill 擅自制造。
4. **不确定性可以保留。** 找不到可靠来源、证据相互冲突或因果无法确认时，应明确写出限制。
5. **人工审核不可跳过。** 这些技能提供结构与检查，不替代使用者的最终责任。

## 命名方式

每个技能使用一个稳定、便于记忆的英文名称；该名称同时用于目录、调用与公开展示。功能说明使用中文，避免使用泛化的“助手”命名。
