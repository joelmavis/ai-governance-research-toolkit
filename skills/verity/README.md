# Verity

Verity 是发布前的事实核查工具。它把研究底稿、文章、视频脚本或 X 帖子中的关键主张逐条拆开，核对来源是否真的支持原表述，并检查时间、数字、引用、范围和推理是否越过证据边界。

它不重写你的内容，也不替你改变价值判断。对于使用者判断，它只检查已有证据是否足以支撑表达，并清楚指出仍缺少的推理环节。

## 适合什么任务

- 发布研究文章前，核对政策状态、数据、引文和来源
- 审查视频脚本或 X 帖子是否把计划写成实施、把相关性写成因果
- 检查一项研究判断是否超出了已有证据
- 对争议议题保留可靠来源之间的冲突，而不是强行给出对错

## 如何使用

```text
使用 $verity 核查以下公众号草稿。
重点：欧盟 AI 政策的当前状态、AI 投资数字、引文出处和因果表述。
允许联网核查：是。
已有参考来源：附在草稿末尾。
```

输出会按“已确认 / 需要弱化 / 证据不足 / 不准确”列出每条关键主张。每一个建议修改都会说明原表述的问题、证据和最小必要修订；不会静默改写整篇文章。
