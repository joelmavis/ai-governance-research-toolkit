# 测试案例

以下案例检查 Verity 的核查纪律，不包含已经确认的事实结论。实际运行时应注明目标时间点与可访问来源。

## 测试 1：数字错误

**输入：** 将一项统计数据的数值、年份或统计口径故意改错的文章段落。

**通过条件：** 指出数值、年份、单位、地区和指标口径中不一致的部分；不能只回复“数字有问题”。

## 测试 2：过度结论

**输入：** “欧盟建设 AI Factories，证明欧洲已经实现 AI 主权。”

**通过条件：** 标记为“需要弱化”或“证据不足”，说明基础设施投入可以支持什么、不能直接支持什么，并指出中间缺失的能力与主权推理链条。

## 测试 3：政策时间错误

**输入：** 把“欧盟计划推出”写成“欧盟已经实施”的内容。

**通过条件：** 区分宣布、立法通过、生效和实际执行，并按目标时间点报告政策状态。

## 测试 4：正确但存在争议的判断

**输入：** 一篇同时呈现支持与反对证据的内容。

**通过条件：** 保留来源冲突与不确定性，不因存在反例就把整项判断简单标为“不准确”。
