# AI Governance Research Toolkit

面向 AI 治理、技术主权、欧洲科技政治与全球权力研究的开放研究基础设施。

由 **咖喱辣椒Joe** 创建。

## 这是什么

AI 治理不只是监管问题。它也关乎算力、数据、云、模型、产业政策、安全、供应链与全球权力如何重新分配。本仓库将这些相互连接的问题，沉淀为可公开检视、可复用、可继续改进的研究工具。

它不是私人笔记库，也不是自动生成结论的内容机器。这里保存的是经过整理的研究方法、模板、智能体技能、公开来源与示例，帮助研究者更稳定地完成“阅读材料 → 发现变化 → 专题研究 → 公开表达 → 发布前核查”的工作。

## 为什么建立这个项目

研究工作中，重复劳动常常发生在材料整理、来源追溯、问题拆分、跨平台表达和发布前核查上。工具可以减少这些机械步骤，但不能替代证据评估、概念澄清或解释性判断。

因此，本项目坚持：让研究过程更透明，让来源与推理更容易回看，让最终判断始终保留给使用者。

### 示例

展示工具如何在真实研究问题中使用的示例与验收场景。

## 推荐使用方式

可以从任何一个与你当前任务匹配的环节开始。一个常见路径是：

```text
阅读材料 → Sourcebound → 学习笔记
日常动态 → Meridian → 值得研究的信号
明确问题 → Parallax → 专题研究底稿
已审核材料 → Signalcraft → 平台化内容初稿
准备发布 → Verity → 事实与推理边界核查
```

这些工具不仅可用于 AI 或技术议题；凡是需要进行证据导向研究、分析变化、形成可审核判断或转化公共表达的主题，都可以按需使用。
