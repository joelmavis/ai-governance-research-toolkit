# AI Governance Research Toolkit


面向 AI 治理、技术主权、欧洲科技政治与全球权力研究的开放研究基础设施。


由 **咖喱辣椒Joe** 创建。


## 为什么建立这个项目


AI 治理日益与技术、主权、安全、产业政策和全球权力相互连接。


本仓库为研究这些变化的人提供实用工具。目标不是自动化智识判断，而是在不取代判断的前提下，减少重复劳动，使研究更结构化、更透明、更可复用。


## 研究方向


- AI 治理
- 技术主权
- 欧洲科技政治
- 中美欧技术关系
- AI 安全与保障
- AI 基础设施与政治经济学
